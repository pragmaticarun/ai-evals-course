# MediaDoctor knowledge base, second edition (module 7)

A larger corpus of short, original notes written for this course: 25 documents, each split into
sections with `##` headings. Module 7 uses it to evaluate retrieval on its own, before it replaces
the module 1 knowledge base in `data/kb/` (which the agent and the recorded fixtures still use).

Section ids are `<document>#<n>` where n counts the `##` sections from 1.
