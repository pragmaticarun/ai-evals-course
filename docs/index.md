# AI Evals, Hands-On

An original, self-paced course on evaluating LLM agents. You build one agent, **MediaDoctor**, which answers Android
and multimedia debugging questions, and you work through the whole eval loop with it: find where it breaks, measure
those failures with evaluators you can trust, and improve it with evidence.

- **12 modules**, about 87 hours in total (an estimate), designed for about 7 hours a week.
- **Hands-on**: every module has a lab that runs offline from recorded model responses, exercises with
  collapsed solutions, and a quiz.
- **Live runs on Claude** through the Anthropic Python SDK when you want them; CI never needs a key.
- **A capstone**: a complete [eval report](capstone/index.md) on MediaDoctor, generated from every module's
  artifacts, and the tools to write your own.

New here? Read **[Start here](start-here.md)** for a 13-week study plan at about 7 hours a week.

!!! warning "The data in this course is synthetic"
    MediaDoctor's questions, knowledge base, scenarios, and attacks were **written for the course** by the scripts
    in `scripts/`. Every recorded model response was then **generated by Claude subagents** standing in for the API
    (Sonnet for the agent, Haiku for the judges and synthetic data) and is labelled `"source": "subagent-authored"`;
    the reference labels were written by Claude Opus subagents. That makes every lab reproducible offline. No
    failures are planted and the agent fails rarely, so some labs have only a handful of failures to find; each says
    what its method would show on data with more. The rates you measure describe the method on this data, not how
    Claude models behave through the API: re-record live with your own key before using any number for a real
    decision. The code (agent, tools, checks, judges, statistics, CI gate) is real.

## Who it is for

Experienced engineers who are comfortable with Python, git, and the command line. No ML background is assumed.
Examples lean on Android media and multimedia, but each one is explained as it comes up.

## Standing on shoulders

The structure of this course is inspired by Hamel Husain and Shreya Shankar's work on AI evals, including their
Maven course and public writing. All text, code, and data here are original. See [Credits](credits.md).

Start with [Setup](setup.md) and the [study plan](start-here.md), then work through the modules in order, from
[Module 1](modules/01-why-evals/index.md) to the [Module 12 capstone](modules/12-capstone/index.md). Keep the
[cheat sheets](cheatsheets/index.md), [templates](eval-templates/index.md), and [glossary](glossary.md) at hand.
